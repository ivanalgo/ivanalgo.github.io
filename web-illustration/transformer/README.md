# Transformer Trace Lab

无需安装依赖的宽幅桌面网页，用确定性的微型 Transformer 展示完整前向传播。

## 启动

直接在桌面浏览器打开 `index.html`，或在本目录运行：

```bash
python3 -m http.server 4173
```

然后访问 http://localhost:4173 。

## 功能

- 自定义中英文输入，最多 8 个 token；超出长度会明确提示。
- 87 个计算与参数节点逐步生成，已生成的结果一直保留，也可一次展开全部。
- 所有计算统一为“输入 → 运算圆圈 → 结果”；矩阵乘法 ×、相加 +、逐元素缩放 ⊙ 等具有不同标记。
- 同轴上下游使用直线，参数水平接入运算圆圈；分支与残差旁路使用圆角正交连线。
- Token 向量、位置编码及相加结果分别显示。
- 三处 LayerNorm 均展示均值、方差、标准化、γ 缩放和 β 平移；均值与方差位于主矩阵侧边。
- 两个注意力头左右并列，分别显示 Q/K/V 权重、bias、乘积和投影结果；K 转置、Mask、Softmax 和注意力加权均显式展示。
- 显示输出投影、残差、MLP、最终 LayerNorm、最后 token 选择、词表投影及采样中间结果。
- 参数卡片解释每行、每列与参数用途，支持收起/展开。
- 点击矩阵单元格可查看具体展开式，并联动高亮上游输入行、权重列和 bias；新增步骤与切换精度保留选中。
- 支持缩放、步骤导航、定位最新、自动跟随开关、空格拖拽和键盘选择。
- 可调 Temperature、Top-k 和显示精度；修改设置后会提示重新计算。
- JSON schema v2 导出全部参数、张量、依赖图与教学规则；负无穷编码为字符串 `"-Infinity"`。

## 模型与验证

这是固定生成参数的教学模型：1 个 Transformer Block、2 个注意力头、`d_model=4`、`d_ff=8`。分词使用教学规则与哈希 ID，不是 GPT-2 BPE；位置编码使用固定 sin/cos 规则，不使用 GPT-2 预训练权重，不用于生成高质量文本。

计算图包含 10 份独立权重矩阵和 16 份 bias/LayerNorm 参数向量；合并与分头 QKV 不重复计算独立参数数量。所有 Linear 均分开显示矩阵乘积与 bias 相加。

发布前已在原开发工作区完成 54 组输入/Temperature/Top-k 回归，与原版比较 29,970 个数值，最大误差为 0；因果性、参数完整性和 JSON 导出检查通过。桌面浏览器检查覆盖默认输入、8 token、六位精度、参数折叠及增量生成；所测路径没有穿越矩阵卡片、标题或运算说明。路径采样不是任意环境下的形式化避障保证。

运行仅依赖 `index.html`、`styles.css`、`model.js` 和 `app.js`，无需构建。
