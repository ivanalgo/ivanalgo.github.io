# Appearance & Fashion illustrations

Generated with the built-in imagegen tool, one call per image. Exact prompts are in [appearance-image-prompts.json](../../../data/appearance-image-prompts.json).

The published assets are WebP derivatives encoded at quality 86 without cropping or resizing. Original generated PNGs are retained locally and at imagegen's original save paths, but are excluded from Git to reduce download and repository size.

Each scene has one overview and ten distinct word images. No generic icon placeholders.
